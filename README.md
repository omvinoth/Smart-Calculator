# 🧮 Smart Calculator – Python Mini Project

A Python-based Smart Calculator project developed to practise Python programming and build practical coding skills.

Smart Calculator is a mini project built using Python. It provides a simple way to perform calculations through a Python program.

- Simple calculator interface
- Python-based implementation
- Easy to understand code
- Beginner-friendly project

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Open the terminal.
5. Run:

```bash
python calculator.py
```
